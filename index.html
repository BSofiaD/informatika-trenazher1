📚 Теория

Системы счисления

Система счисления — это способ записи чисел с помощью определённого набора цифр.

В двоичной системе используются только две цифры: 0 и 1.

Алгоритм

Алгоритм — это последовательность действий, которая приводит к решению определённой задачи.

Информация

Информация — это сведения об объектах, событиях и процессах окружающего мира.

HTML, CSS и JavaScript

HTML создаёт структуру веб-страницы.

CSS отвечает за внешний вид сайта.

JavaScript добавляет интерактивность.

🔎 О проекте

Данный сайт создан в рамках исследовательского проекта «Разработка образовательного сайта-тренажёра для подготовки к ОГЭ по информатике».

Цель проекта — создать простой цифровой инструмент, который позволяет школьникам самостоятельно повторять материал и выполнять тренировочные задания по отдельным темам.
